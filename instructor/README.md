# Notas del instructor

Esta carpeta es para material que **no debe ver el estudiante**: guiones
privados, notas de calibración de tiempos, respuestas al taller antes de que
se publiquen, listas de errores recurrentes por cohorte, etc.

Hoy está vacía. El guión público de cada clase vive en el `README.md` de la
sesión correspondiente, dentro de [`../sesiones/`](../sesiones/).

Cuando aparezca contenido privado, un patrón razonable es:

```
instructor/
├── guion-s01-detalle.md
├── guion-s02-detalle.md
├── calibracion-tiempos.md
└── errores-recurrentes.md
```
